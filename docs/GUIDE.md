# OrgMap Lab — Field Guide (moved)

The field guide now lives in one place, as a page rather than a file:

**<https://ludwa6.github.io/orgmap-lab/docs/field-guide.html>**

Three deployments link to that URL from their `manifest.guideUrl`, so it is read
directly rather than copied. Corrections go to [`docs/field-guide.html`](field-guide.html)
in this repository — the source of that page, and the only canonical copy.

This file used to hold a Markdown twin of the guide. It went stale, while still
claiming to be the version to correct first, so it was retired on 2026-09-01
rather than reconciled. Its last full text remains in the git history of this
file.
